Universal Subspace Viewer

Loong: original vs UniSub reconstruction

This viewer compares the original GeomDist loong point cloud with its UniSub reconstruction. The meshes are loaded from committed PLY assets in assets/showcase/. Serve this file through GitHub Pages or a local static server such as python -m http.server from the repo root.

Original

Reference point cloud exported from the validated GeomDist run.

UniSub reconstruction

UniSub projection under the retained shared basis.

Drag to orbit, scroll to zoom, and compare the retained geometry. The same assets also appear as a static comparison panel in GeomDist/README.md.
